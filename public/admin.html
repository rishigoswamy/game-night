Removing a fingerprint / Touch ID entry

Turning device unlock off (or removing the lock) stops this site from using it. Newer Chrome also deletes the saved entry automatically. If an entry named Game Night (or Duel Casino / Casino, from before the rename) / table-admin is still listed, delete it here:

  • Mac, Chrome: open chrome://password-manager/passwords, search localhost, open the passkey and choose Delete. If Chrome saved it to iCloud Keychain, use the Passwords app below instead.
  • Mac, Safari or iCloud Keychain: open the Passwords app (or System Settings → Passwords), search localhost, select the passkey and delete it.
  • Android: Settings → Passwords & accounts → Google (Google Password Manager), find the site's passkey and delete it.
  • iPhone / iPad: Settings → Passwords (or the Passwords app), find the site and delete the passkey.

A passkey can only be created on https or localhost, so phones using the plain Wi-Fi address never have one. A left-over entry is harmless; it just takes up a line in the list.
